# PacketSnifferAnalyzer — Plugin Directory
#
# Place your custom plugins in this directory.
# Each plugin must be a Python package (directory with __init__.py)
# that implements the PluginInterface from:
#   packetanalyzer.plugins.interface.PluginInterface
#
# The plugin manager discovers plugins here automatically at startup.
#
# See docs/plugins.md for the plugin development guide.
# See examples/plugins/ for example plugin implementations.
#
# SECURITY WARNING:
#   Only install plugins from sources you trust.
#   Plugins have access to dissected packet data.
#   Plugin signature verification is on the roadmap.
