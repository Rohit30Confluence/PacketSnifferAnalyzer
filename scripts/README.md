# Scripts

This directory contains utility scripts for development and operations.

| Script | Description |
|---|---|
| `setup-dev.sh` | Set up the development environment |
| `generate-test-pcap.sh` | Generate synthetic PCAP fixtures for tests |
| `check-privileges.sh` | Check capture privileges and provide remediation |

## Usage

```bash
# Set up development environment (run once after cloning)
bash scripts/setup-dev.sh

# Generate test PCAP fixtures
bash scripts/generate-test-pcap.sh

# Check capture privileges
bash scripts/check-privileges.sh
```
