01

What it does

One capture engine, three ways to look at the same traffic.

Capture

Live packet sniffing

Pulls traffic straight off a network interface, packet by packet.

Analyze

Protocol breakdown

Separates traffic by protocol so patterns are visible at a glance, not buried in a scroll of hex.

Inspect

Packet-level detail

Drill from a summary view down into the individual packet when something looks worth a closer look.

Visualize

Dashboard view

Traffic volume, protocol mix, and top talkers rendered as a live picture instead of a log file.

02

How it's structured

One capture core feeding three independent front ends — so the CLI, GUI, and dashboard stay in sync without duplicating logic.

Roadmap

Where the project is headed, in order.

v0.1
Capture core. Interface selection, raw packet capture, basic protocol parsing (Ethernet/IP/TCP/UDP).
v0.2
CLI. Filterable live capture output, save/load capture files.
v0.3
GUI. Desktop packet list and inspector view.
v0.4
Dashboard. Aggregate traffic visualization — volume, protocol mix, top talkers.
